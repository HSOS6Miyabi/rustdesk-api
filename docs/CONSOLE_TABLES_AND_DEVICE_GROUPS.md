# 控制台表格与设备分组

## 表格信息

用户分组显示成员数、成员名下的设备数、公共成员数、创建者和创建时间。同一用户同时具有主要分组关系和附加成员关系时，成员数只计算一次。公共成员数只适用于公共锚点组。

设备分组显示设备总数、近期活跃设备数、组安全策略、组控制角色、最近活动和修改时间。近期活跃设备数按最近两分钟收到的心跳计算；最近活动取组内设备最后一次心跳的时间。组策略和组控制角色表示分组上的配置，单台设备和设备所有者上的设置仍按原有优先级生效。

用户账户显示账户类型、名下设备数、主要分组、状态、创建时间及备注。OIDC / SSO 列表显示自动注册、自动加入分组和 PKCE 配置。地址簿分类、设备标签及策略和角色分配列表显示创建、修改时间。

编号和数量列采用紧凑宽度，名称、邮箱和说明字段可使用剩余空间。拖动列标题右侧边缘可以调整列宽，双击边缘可以根据该列内容调整宽度。使用“根据内容调整列宽”可同时调整各列。列宽保存在当前浏览器中。

窗口较窄时，次要字段可通过“查看详情”展开；“显示全部列”可以查看所有字段。手机和平板显示记录卡片，名称或账户名位于卡片顶部。实时汇总字段没有排序按钮，已有数据库字段继续支持跨页排序。

## 管理组内设备

在“设备管理 → 设备分组”中，点击设备数量或“管理设备”按钮即可打开设备管理界面。

“组内设备”列出已经加入该组的设备。“添加设备”列出其他设备。两种列表均支持按设备 ID、备注、主机名、所有者或分组名称搜索，并以每页 20 台设备分页显示。搜索会查询整个符合条件的设备集合。

选择可以跨页保留。每次最多处理 200 台设备，保存前会显示确认信息。从其他分组加入设备时，原分组关系会同时更新。从当前分组移除设备后，设备变为未分组，设备登记记录、设备 ID、所有者和备注均保持不变。

每次保存都会检查所有所选设备及其原分组。另一位管理员已经修改设备分组时，本次操作将返回冲突信息，并重新读取列表。一次操作中的设备修改在同一数据库事务中完成。

具有 `device_groups.view` 权限的管理员可以查看组内设备。查询待加入设备及修改分组需要 `device_groups.edit` 权限。这两项权限均适用于全局管理范围。

## HTTP 接口

接口前缀为 `/api/admin`，请求使用现有的 `api-token` 认证方式。

| 方法与路径 | 参数与用途 |
| --- | --- |
| `GET /device_group/devices` | 必填 `group_id`；可选 `keyword`、`page`、`page_size`，查询组内设备 |
| `GET /device_group/candidates` | 参数同上，查询其他分组或未分组的设备 |
| `POST /device_group/devices/batch` | 批量加入或移除设备 |

批量请求示例：

```json
{
  "group_id": 3,
  "action": "add",
  "devices": [
    {"row_id": 12, "expected_group_id": 0},
    {"row_id": 18, "expected_group_id": 2}
  ]
}
```

`row_id` 使用设备登记记录的主键。`expected_group_id` 必须填写查询时的分组编号，未分组填写 `0`。`action` 可以为 `add` 或 `remove`。成功响应的 `data.affected` 为实际修改的设备数量；原分组发生变化时，响应的 `code` 为 `409`。

`GET /group/list`、`GET /my/group/list`、`GET /device_group/list` 和 `GET /user/list` 接受 `summary=1`。分页和权限范围保持不变，响应增加相应的数量及配置字段。服务器按当前页记录批量查询汇总数据。
