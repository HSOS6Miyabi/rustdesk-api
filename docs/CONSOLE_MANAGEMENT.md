# 控制台与服务器管理

本说明适用于 RustDesk API v3.0.0-api.116。登录 `/_admin/`，即可使用设备管理、对象搜索、服务器管理和个人连接记录。

## 桌面页面与表格

控制台会尽量利用桌面窗口的横向空间，表格根据可用宽度显示常用字段。较长的备注、系统名称和 IP 地区信息最多显示两行。点击“查看详情”可以展开其他字段；点击“显示全部列”后，也可以在表格区域左右滚动。点击列标题或从下方选择字段，可对各页记录排序。表格默认每页显示 100 项，也可以选择每页 20 项或 50 项，点击页码可直接跳转。

用户、用户组、设备组及安全策略等关联信息会尽可能同时显示名称和编号。表单通过统一搜索窗口选择对象，支持按名称、编号搜索和连续选择多个对象。相关表单允许手动填写未登记的外部设备 ID。

## 账户与身份认证

个人设置采用自适应卡片布局，电脑宽屏可并列查看账户信息、Passkey、密码和双重认证，手机上按顺序展示。用户可以注册、查看及移除自己的 Passkey，并从登录页面使用已注册的 Passkey 完成验证。

管理员在“用户账户”中打开“编辑用户信息”后，可以修改资料；具有相应权限时，还能在同一界面重设密码或清除 TOTP 与邮箱双重认证。重设密码、清除双重认证后，目标用户当前登录会话会结束。操作步骤见 [Passkey 与账户管理](PASSKEY_AND_ACCOUNT_MANAGEMENT.md)。

## 服务器管理

系统管理员进入一级导航“服务器管理”，可以切换“服务器概况”“ID 服务器”和“中继服务器”。

- ID 服务器将客户端登录要求、强制使用中继和中继地址分别整合为独立设置，进入后自动读取当前状态。IP 封禁和 IP 变化记录也集中显示，并提供对应的管理操作。
- 中继服务器集中管理限速名单、阻止名单和带宽限制。选择查看类功能时自动查询并显示结果，还可查看中继使用统计。
- 结果以状态、数值和表格显示；更改配置后，页面会在适用时重新读取服务器的实际状态。

### 控制端口与部署

| 服务 | 默认管理连接 | API 配置 |
| --- | --- | --- |
| ID 服务器 `hbbs` | `127.0.0.1:21115` | `admin.id-server-port` 减 1 |
| 中继服务器 `hbbr` | `127.0.0.1:21117` | `admin.relay-server-port` |

API 通过本机回环地址向服务端发送管理命令。直接部署时，API 与 `hbbs`、`hbbr` 应运行在同一个网络空间内。在 Linux Docker 环境中，可以让这些服务共同使用宿主机网络；使用 `network_mode: host` 时，请删除与之冲突的 `ports` 映射。

控制命令只应由本机可信任的进程访问，请勿将这些本地管理接口转发到公网。服务器概况中显示的公网地址用于客户端连接，不决定管理命令的目标地址。查询失败时，请先检查服务器进程、控制端口及 Docker 网络设置。

### 管理 HTTP 接口

系统管理员可以向 `POST /api/admin/rustdesk/execute` 提交：

~~~json
{"target":"21115","cmd":"always-use-relay","option":""}
~~~

成功响应的 `data.kind` 描述返回数据的形式：

| 类型 | 含义 |
| --- | --- |
| `boolean` | 当前状态或列表中的匹配结果 |
| `metric` | 数值和单位 |
| `list` | 地址或功能清单 |
| `table` | IP 封禁和变化记录 |
| `usage` | 中继连接和流量统计 |
| `value` | 单项查询结果 |
| `notice` | 已向服务器发送操作请求 |
| `empty` | 当前没有可显示的信息 |

其他字段根据类型包含 `summary`、`rows`、`count`、`value`、`unit`。原有 `POST /api/admin/rustdesk/sendCmd` 仍可供现有程序调用，继续返回文本字符串。

## 个人远程连接与登录会话

普通用户可以使用“我的活动远程连接”“我的结束连接记录”“我的登录会话”。活动连接仅展示本人名下设备的连接；请求结束连接后，客户端接收通知才会结束对应连接。个人结束连接记录展示本人发出的请求及本人名下设备相关记录。

登录会话页面提供客户端、登录 IP、登录时间、设备标识和有效期，可以撤销不再使用的登录会话。当前会话会单独标明；撤销当前会话后，需要重新登录。会话列表不会返回登录令牌原文。历史数据没有记录终端信息时，页面会明确说明。

管理员可使用“活动远程连接”“结束连接记录”和“全部登录会话”查看相应记录。活动远程连接会显示连接双方的设备信息、设备所有者和可用的操作系统用户名；连接方资料未记录时会显示空值。

### 个人 HTTP 接口

| 方法 | 地址 | 功能 |
| --- | --- | --- |
| GET | `/api/admin/my/session/list` | 查看名下设备的活动连接 |
| GET | `/api/admin/my/session/disconnect/list` | 查看结束连接记录 |
| POST | `/api/admin/my/session/disconnect` | 请求结束名下设备的连接 |
| GET | `/api/admin/my/user_token/list` | 查看自己的登录会话 |
| POST | `/api/admin/my/user_token/revoke` | 撤销自己的登录会话 |

结束远程连接时提交：

~~~json
{"device_id":"123456789","conn_id":123}
~~~

撤销登录会话时提交：

~~~json
{"id":15}
~~~

管理员对应使用 `/api/admin/session/list`、`/api/admin/session/disconnect/list`、`/api/admin/session/disconnect`、`/api/admin/user_token/list` 和 `/api/admin/user_token/delete`。列表接口可使用 `page`、`page_size`、`sort_by`、`sort_dir` 参数。

## 测试和升级

项目自动检查 Go 后端、浏览器交互、前后端 HTTP 请求、模拟 RustDesk 控制端口回复，以及 SQLite、MySQL、PostgreSQL 的数据库升级过程。正式升级前，应备份数据库、RustDesk Server 身份密钥、API 配置和加密密钥。具体操作见 [部署与配置](DEPLOYMENT.md)。

## 页面资源更新与浏览器缓存

控制台的脚本和样式文件使用根据内容生成的资源地址。文件内容发生变化后，资源地址会随之改变，浏览器和 CDN 会自动获取新的文件。未变化的文件继续使用现有缓存。入口网页会向服务器核对缓存是否需要更新。

页面底部的“控制台资源版本”可用于检查浏览器是否已经获取当前服务上的页面。服务器的 `/_admin/` 响应头也包含 `X-RustDesk-Console-Revision`，可用以下命令检查：

```bash
curl -I https://你的服务器域名/_admin/
```

使用仓库提供的 Docker Compose 文件更新软件时，执行：

```bash
docker compose pull rustdesk-api
docker compose up -d --force-recreate rustdesk-api
```

Compose 默认使用 `ghcr.io/hsos6miyabi/rustdesk-api:latest`，并设置 `pull_policy: always`。运行 `docker compose up -d` 时会检查并获取最新正式版镜像，有更新时会重新创建容器。升级完成后，可以在浏览器中重新进入控制台，检查底部显示的资源版本。如果 CDN 自行设置了入口网页的缓存规则，请让 `/_admin/` 和 `/_admin/index.html` 遵循服务器返回的缓存响应头。
