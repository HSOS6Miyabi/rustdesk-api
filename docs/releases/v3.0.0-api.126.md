# v3.0.0-api.126

## WebClient 远程操作

- 剪贴板共享在桌面连接建立后自动启用，浏览器与远程设备之间可传输文本。远程桌面获得键盘焦点后，Ctrl+C、Ctrl+V 及其他常用组合键会直接传递到远程设备。
- 复制远程文件后，可使用“下载剪贴板文件”保存文件；下载结束后，提示会自动消失，也可以随时关闭提示。关闭提示不会取消正在进行的传输。
- 浏览器无法直接读取文件管理器复制的系统文件时，点击“选择文件并粘贴到远程”可以选择本机文件，待远程端确认剪贴板格式后，将其粘贴到远程文件管理器。
- RustDesk 内置全屏按钮会切换至仅显示远程画面的全屏布局。按 Esc 可以退出。
- 文本和文件剪贴板仍受远程系统权限、浏览器安全权限及对方客户端支持情况限制。远程文件复制到本机时通过浏览器下载完成，本机文件上传还可以使用“文件”标签。

## 兼容性

在 HTTPS 环境下使用支持 Clipboard API 的浏览器可获得更完整的文本同步功能。个别浏览器会要求通过用户点击操作授权读取或写入剪贴板。操作系统和浏览器保留的全局快捷键可能无法交给网页处理。

## 验证

WebClient 运行测试检查远程快捷键、文件复制和下载、文件列表更新、通知关闭与自动消失，以及原生全屏布局。自动化发行流程还运行 Go、数据库和浏览器端到端测试。
