# v3.0.0-api.125

本次更新完善 SSO 和 LDAP 用户的备用登录方式。

- SSO 和 LDAP 用户可以在“个人设置”中直接设置自己的第一个本地密码。
- 已有本地密码的账户修改密码时仍需要验证当前密码。
- 用户成功设置或修改本地密码后，原有登录会话会失效。
- 已设置的本地密码会优先在服务器本地验证，即使 LDAP 暂时无法连接，也可以登录。
- “个人设置”会根据账户是否已有本地密码显示相应表单。
- 已登记的 Passkey 可以继续在管理控制台独立使用。

使用方法见 [个人账户与 Passkey 登录](../PASSKEY_AND_ACCOUNT_MANAGEMENT.md)。
