# RustDesk API v3.0.0-api.108

发行日期：2026 年 11 月 12 日  
数据库迁移版本：**290**

本次更新改进设备和用户管理、服务器管理及 WebClient 的操作界面，并完善电脑、平板和手机上的显示方式。

## 主要功能

- **我的设备**：普通账户可以查看、修改备注并删除自己拥有的设备。管理员的“设备管理”采用独立导航入口，管理操作继续检查授权范围。
- **设备和用户信息**：点击列表及关联字段中的设备名称、设备 ID 或用户名可以查看详情。绿色圆点表示在线，红色圆点表示离线，灰色圆点表示状态暂时无法确定。
- **导航和表格**：一级导航分类可以折叠，切换页面时保留侧边栏的滚动位置。表格列标题支持对当前页记录排序；手机页面提供排序字段和方向选择。
- **搜索及颜色选择**：在设备、用户、共享规则及分组等页面搜索并选择关联对象；设备标签可以选择颜色和透明度。
- **服务器管理**：分别列出 ID 服务器和中继服务器的管理操作。每项操作说明用途及参数，浏览器和 API 均会检查相关参数。
- **WebClient v2**：可选择网页全屏或显示器全屏，两种模式均可退出；可搜索本人设备及共享设备，并通过设备名称和用户名查看对应信息。
- **界面布局**：改进表格列宽、按钮间距和窄屏显示。浏览器测试使用简体中文字体检查页面及表单。

## 升级

升级前请备份 SQLite、MySQL 或 PostgreSQL 数据库，并妥善保存配置文件及加密密钥。此次升级保留数据库迁移版本 **290**，无需新增迁移操作。普通服务器和 Docker 部署方式保持不变。

Docker 镜像：

```bash
docker pull ghcr.io/hsos6miyabi/rustdesk-api:v3.0.0-api.108
docker compose pull
docker compose up -d
```

Docker 安装请继续持久保存 `/app/data`。更新后重新启动 API，并刷新管理控制台及 WebClient 的网页。

## 使用与测试

管理控制台地址为 `/_admin/`，WebClient 地址为 `/webclient2/`。设备信息及管理操作受到当前账户权限限制。执行服务器管理操作前，请确保 API 主机可以访问相应 RustDesk Server 管理端口。

使用 GitHub Actions 检查 Go、前端交互、Chromium 页面、数据库升级、客户端构建和多种屏幕尺寸。真实远程设备连接、生产数据库恢复及邮件服务应在对应部署环境中检查。

详情参阅 [部署说明](../DEPLOYMENT.md)、[功能说明](../FORK_CHANGELOG.md)、[兼容性](../COMPATIBILITY.md) 和 [测试方法](../TESTING.md)。
