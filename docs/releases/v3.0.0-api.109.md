# RustDesk API v3.0.0-api.109

发行日期：2026 年 11 月 12 日  
数据库迁移版本：**290**

本次更新完善个人地址簿和设备标签的操作，改进 WebClient 的请求参数检查，并增加独立 API 集成测试。

## 主要改进

- **个人地址簿**：保存条目时根据登录账户检查记录所有者，保留没有提交修改的连接信息和标签。
- **个人共享与分类**：地址簿分类、共享规则和设备标签的修改使用当前登录账户的用户编号，并检查记录所有者。
- **设备标签颜色**：完整支持 ARGB 颜色与透明度，能够保存完全透明的颜色值。
- **WebClient 请求**：检查分享令牌和设备编号的数据类型，按统一方式返回无效请求的错误信息。
- **接口测试**：根据管理控制台、WebClient v2 和原版 WebClient 发出的请求检查 HTTP 方法、请求路径及返回内容。在临时 SQLite 数据库中验证数据保存和跨账户访问限制。

## 升级说明

数据库迁移版本保持 **290**，已有数据库结构和部署方式无需调整。升级前请备份数据库、配置文件及长期使用的密钥。

Docker 镜像：

```bash
docker pull ghcr.io/hsos6miyabi/rustdesk-api:v3.0.0-api.109
docker compose pull
docker compose up -d
```
