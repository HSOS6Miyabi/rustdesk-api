# RustDesk API v3.0.0-api.110

发行日期：2026 年 11 月 12 日  
数据库迁移版本：**290**

本次发行更新客户端安装包构建器，支持选择不同的 RustDesk 官方正式版本，同时支持在浏览器中处理用户选择的本地安装文件。

## 主要功能

- **官方正式版本**：根据版本号查询 RustDesk 官方 GitHub Release，自动识别 Windows、Linux、macOS 的 x64 和 ARM64 安装文件。可选择近期版本，也可输入此前已发行的版本号。
- **官方下载校验**：核对官方文件大小。官方提供 SHA-256 时进行比对；未提供官方摘要的旧版本下载后计算并保存 SHA-256，便于后续下载验证。
- **浏览器本地处理**：允许选择本地 EXE、DEB、DMG。Windows 使用包含服务器配置的安装文件名，原始 EXE 字节保持不变；Linux 和 macOS 将原始文件、配置脚本、使用说明打包为 ZIP。
- **文件隐私**：本地安装文件不上传服务器，不计算 SHA-256。生成 ZIP 时只计算 ZIP 格式所需的 CRC-32。
- **自动化检查**：覆盖不同官方版本、平台匹配、下载校验、浏览器本地生成、文件内容保持、ZIP 内容和配置脚本。

## 使用与升级

管理员登录 `/_admin/`，打开“客户端安装包构建”即可选择所需方式。早期客户端的安装参数和服务器设置支持情况可能不同，应在目标系统上检查安装与远程连接。

数据库结构保持版本 **290**，普通进程和 Docker 部署方式不变。升级前备份数据库、启动设置和密钥。配套 RustDesk Server 版本保持 `v1.1.17-api.21`。

更多信息见 [客户端构建器使用说明](../CLIENT_BUILDER.md)、[兼容性](../COMPATIBILITY.md) 和 [测试说明](../TESTING.md)。
