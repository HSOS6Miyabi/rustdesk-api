# v3.0.0-api.136

## WebClient 访问权限

WebClient2 和 RustDesk 原版 WebClient 的网页、脚本、WebAssembly 文件与其他静态资源都需要有效的管理后台登录会话。服务器会检查浏览器会话所对应的账户状态和令牌有效期。访客访问页面时会进入管理后台登录页；未登录请求无法读取远程连接组件文件。

账户登录、Passkey 登录和单点登录成功后，服务器会为浏览器设置具有 HttpOnly、SameSite 属性的会话 Cookie。通过 HTTPS 访问时设置 Secure 属性。浏览器关闭后会话 Cookie 失效；用户退出登录、撤销令牌、令牌过期或账户被停用后，服务器会拒绝后续 WebClient 请求。受保护的资源使用禁止缓存的响应标头。

从设备列表打开 WebClient2 时，用户可以沿用管理后台已建立的登录状态。需要重新登录时，服务器会保留受限的 WebClient2 返回路径及设备 ID、名称，登录成功后返回对应设备。单点登录和普通登录均支持这一流程，返回路径仅允许站内 WebClient2 地址。

## 服务器设置

通过包含设备 ID 的链接进入 WebClient2 时，ID 服务器和公钥配置默认折叠，并保持可手动展开。即使浏览器未保存连接参数，或读取服务器设置失败，也会保持折叠状态。直接访问 WebClient2 进行手动连接时，配置区默认展开。

## 测试

自动化测试检查匿名访问、授权访问、会话到期、会话撤销、账户停用、浏览器 Cookie 属性、单点登录返回地址以及设备链接的设置折叠行为。Chromium 浏览器测试保存手机页面的截图，供视觉检查。
