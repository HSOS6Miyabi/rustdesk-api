# RustDesk API v3.0.0-api.111

发行日期：2026 年 11 月 12 日  
数据库迁移版本：**290**

本次发行完善控制台设备与用户查询、共享设备详情及分页排序，保留 RustDesk 官方客户端多版本安装包构建功能。

## 管理界面与设备查询

- **导航折叠**：每个一级导航分类均可单独折叠，折叠状态会保留。切换页面时保留导航滚动位置。
- **完整数据排序**：点击表格列标题可以对数据库中的完整记录排序，再按分页返回结果；支持升序和降序，手机页面同样可以选择字段。
- **用户和设备搜索**：可以按用户编号、用户名、昵称、邮箱等信息查找用户；设备搜索支持设备 ID、备注、主机名、系统和相关账户信息。搜索时遵守账户访问权限。
- **共享设备详情**：具有共享权限的账户可以查看共享设备信息。撤销共享后，再次查询设备会受到访问权限限制。
- **设备白名单**：可搜索并选择多个设备，也可添加外部设备 ID 和匹配规则；留空时按策略适用范围处理。
- **交互与布局**：改善导航和选择器在不同屏幕尺寸下的操作，完成桌面、平板、手机浏览器检查。

## 前后端接口

服务端根据经过检查的数据库字段处理排序参数，SQL 参数采用安全方式传递。前后端集成测试以管理员和普通账户身份发送真实 HTTP 请求，检查数据保存、共享访问、排序以及常见管理功能。

## 版本与升级

SQLite、MySQL 和 PostgreSQL 继续使用迁移版本 **290**，无需额外迁移步骤。普通服务器和 Docker 的部署方式保持一致。升级前请备份数据库、配置及加密密钥。

Docker 镜像：

```bash
docker pull ghcr.io/hsos6miyabi/rustdesk-api:v3.0.0-api.111
docker compose pull
docker compose up -d
```

升级后可以在 `/_admin/` 检查导航、设备列表与排序，在 `/webclient2/` 检查远程连接界面。实际设备连接及外部身份服务的运行情况请在相应部署环境中确认。

参阅 [升级说明](../UPGRADE.md)、[接口测试说明](../TESTING.md) 和 [功能清单](../FEATURE_MATRIX.md)。
