# v3.0.0-api.121

## Redis 与缓存

- API 未配置 Redis 时，默认使用有容量限制、按有效时间自动清理的内存缓存，普通功能可以直接运行。
- 配置 Redis 后，默认缓存会复用 Redis 连接。需要时仍可选择内存缓存或文件缓存。
- OAuth 登录、账户绑定的短期授权状态使用所选缓存。多个 API 实例共用 Redis 缓存时，授权回调可以在不同实例完成。
- 配置 Redis 时，登录失败次数、IP 封禁记录和验证码在各实例间共享。验证成功的验证码会立即失效；Redis 暂时不可用时继续检查本机记录。
- 管理员修改设备策略及通知设置后，使用 Redis 的多个 API 实例会收到缓存更新通知。设备心跳继续使用本机短期缓存，避免增加不必要的网络请求。
- 配置仅有缓存 Redis 地址的部署也可使用 Redis 实例间 SSE 转发。

## 配置方式

单实例安装可以直接沿用现有配置，无需添加 Redis。

需要多实例共享缓存时，设置 `RUSTDESK_API_REDIS_ADDR` 为 Redis 服务地址。使用单独的缓存 Redis 时，设置 `RUSTDESK_API_CACHE_TYPE=redis` 和 `RUSTDESK_API_CACHE_REDIS_ADDR`。如要指定本地缓存，可以将 `RUSTDESK_API_CACHE_TYPE` 设为 `memory` 或 `file`。

多实例共享数据库时仍可启用 `RUSTDESK_API_MULTI_INSTANCE_CACHE=1`，缩短设备策略与通知缓存的重新查询间隔。其余配置和升级步骤参见 [配置说明](../CONFIG_REFERENCE.md)及[部署说明](../DEPLOYMENT.md)。
