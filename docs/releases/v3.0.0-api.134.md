# v3.0.0-api.134

## 移动端单点登录

OIDC 身份认证完成后，管理后台通过带有一次性授权状态的回调地址恢复登录。授权状态放在 URL 片段中，浏览器不会将其作为 HTTP 请求参数发送至服务器。控制台取得登录令牌后会清除地址栏中的授权状态，同时保存管理后台会话。

移动端在身份认证期间打开新的浏览器标签页或窗口时，也可通过回调页面完成登录。对于以前保存于浏览器会话存储空间中的授权状态，继续保留兼容处理。

从 WebClient2 发起的单点登录会把固定返回目标 `/webclient2/` 与授权状态一同保存。认证完成后，网页会进入 WebClient2。返回目标只接受这一固定地址。

授权状态无效、过期或网络请求失败时，管理后台会显示具体提示。临时网络故障可手动重试，过期的授权状态需要重新发起认证。

## 测试

使用 Go 测试验证回调地址、返回目标限制及授权缓存内容。使用 Node.js 测试检查新标签页中缺少原始会话存储空间、过期状态、网络请求失败和 WebClient2 返回操作的行为。Chromium 测试覆盖手机尺寸的登录成功页面、错误提示页面和 WebClient2 返回页面，并保存测试截图。
