# v3.0.0-api.131

## 设备管理

设备列表和共享设备列表会把设备的备注与主机名放在设备 ID 列，显示为“备注（主机名）”，设备 ID 位于下一行。无备注时显示主机名。设备在线状态保留在名称左侧，不再为主机名单独设置一列。

桌面表格的时间信息分为日期和时间两行，时间列默认更窄。宽屏界面会将多余空间优先分配给设备名称、共享来源等文字内容。手动修改过的列宽仍会保留。

转移设备所有者时，界面会单独显示当前所有者，要求明确选择新所有者。可选择的用户中不会包含当前所有者或停用账户，服务器也会拒绝转移给当前所有者的操作。

## WebClient 剪贴板

在 `resources/web/js/src/browser_clipboard_files.mjs` 中将 `MAX_TOTAL_BYTES` 调整为 512 MiB（536,870,912 字节），单个文件和单次文件列表共用此上限。一次最多可传输 256 个文件，文件内容仍按 256 KiB 分段读取。增加上限后，浏览器下载较大的文件仍需有足够的可用内存。

## 验证

增加管理后台设备名称、时间列与所有者转移弹窗的测试，并验证剪贴板文件在 512 MiB 边界上的行为。
