# v3.0.0-api.130

## WebClient 键盘输入

远程桌面获得焦点后，网页会将字母、数字、空格、方向键、功能键和组合键发送到远程设备。按键的按下、释放和长按重复操作均会传递，中文输入法完成输入后也会发送对应文字。网页的连接设置、密码输入和其他普通表单仍可正常填写。

远程桌面使用的 Flutter 隐藏输入框会按远程键盘处理。退出全屏仍可使用 Esc。浏览器或操作系统保留的少数全局组合键，能否转发由浏览器及系统决定。

## 画面性能

VP9 视频帧完成解码后，网页先向远程设备确认接收，再更新画面，以减少同步画面绘制操作对后续视频传输的影响。

连接设置区域会显示当前会话的帧率、视频解码及排队时间、画面绘制时间和连接方式。解码及绘制耗时较长时，可以降低远程画质或屏幕分辨率；如果这些耗时较短但操作仍有明显延迟，可以分别尝试 WebRTC 直连和 WebSocket 连接，并检查网络质量。程序暂时无法仅凭浏览器端数据测出完整的网络往返延迟。

## 按钮位置

网页顶部放置下载远程剪贴板文件、选择文件并粘贴到远程、粘贴本机文本三个按钮。网页全屏和显示器全屏按钮移至左侧连接设置区域。

## 剪贴板文件大小

当前文件剪贴板限制位于 `resources/web/js/src/browser_clipboard_files.mjs`，其中 `MAX_TOTAL_BYTES` 为 256 MiB，`MAX_FILES` 为 256。需要修改时，可调整常量并运行：

```bash
cd resources/web/js
npm ci
npm run build
```

文件下载目前会占用浏览器内存，增加上限时须检查可用内存及文件大小。
