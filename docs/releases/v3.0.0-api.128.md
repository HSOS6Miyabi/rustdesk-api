## WebClient 剪贴板与快捷键

远程桌面连接建立时会请求启用 RustDesk 的文件复制粘贴功能，并同步本机和远程设备的剪贴板使用状态。远程设备允许文件传输后，可在远程资源管理器选中文件，按 Ctrl+C，再点击 WebClient 的“下载剪贴板文件”。

按 Ctrl+C、Ctrl+V 等组合键时，网页客户端会将快捷键发送至远程设备。即使 Flutter 使用隐藏的输入框接收键盘事件，仍会将这些组合键作为远程操作处理。

本机文本复制后，可以直接在远程画面按 Ctrl+V。浏览器需要读取系统剪贴板时，优先由外层 WebClient 页面读取并发送文本。也可以点击“粘贴本机文本”手动读取剪贴板；如浏览器未授权读取，可在出现的输入框中粘贴或输入文本，再点击“发送并粘贴”。

从本机向远程发送文件，可以使用“选择文件并粘贴到远程”或直接向远程桌面拖放文件。浏览器无法直接读取文件管理器复制的文件时，这两种方式仍然可用。

文件复制粘贴还需要远程设备允许键盘输入和文件传输。远程设备安全设置可控制这些权限。

使用快捷键前，请先点击远程桌面画面，使键盘焦点进入远程会话。连接设置中的普通文本输入框仍使用本机快捷键。

## 检查内容

自动化测试覆盖文件剪贴板启用选项、Flutter 键盘输入节点的快捷键、文本共享状态，以及浏览器剪贴板授权成功和拒绝两种情况。还会检查 WebClient 连接、浏览器界面和数据库升级。
