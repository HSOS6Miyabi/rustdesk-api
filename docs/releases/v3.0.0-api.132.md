# v3.0.0-api.132

## 管理后台表格

“我的设备”“设备管理”“共享设备”及其他数据列表在桌面浏览器中会占满所在内容区域。页面较宽时，程序会将空余宽度分配给设备名称、操作系统、IP 地址、设备备注等需要显示文字的列；日期和时间继续在同一单元格内分两行显示，并保持紧凑列宽。

表格保留列排序、手动调整列宽、自动适应内容宽度及按页面宽度显示的操作。较窄屏幕仍按照可用空间选择显示列，并可以查看其余字段。

## 界面检查

Chromium 浏览器测试覆盖多种桌面宽度，并核对表格与所在容器的宽度、页面横向溢出、日期列宽度、时间的双行显示以及操作系统信息的显示空间。测试运行时会保存各页面截图，供人工查看。
