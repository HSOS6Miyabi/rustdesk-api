# RustDesk API v3.0.0-api.114

发行日期：2026 年 11 月 12 日

## 管理控制台

管理控制台的页面能够更充分地使用桌面窗口的横向空间。个人设置采用自适应多列布局，日志保留、SMTP 邮件服务等页面已调整表单与相关操作的排列方式。手机端使用独立的纵向布局。

自动化视觉检查覆盖管理员 51 个导航页面、普通用户 18 个导航页面，分别使用超宽屏、桌面、平板和手机尺寸生成截图，并检查页面溢出、内容截断和明显的空白区域。

## Passkey 与管理员账户管理

用户可以在个人设置中注册、查看及移除 Passkey，并在控制台登录页面使用 WebAuthn 完成登录。每个账户最多可以注册 25 个 Passkey。注册和登录请求有有效期限，每个请求只能使用一次；服务端验证网站来源和认证器签名。

管理员可以根据权限修改用户资料、重设密码，以及清除 TOTP 身份验证器和邮箱登录验证信息。重设密码和清除双重认证后，目标用户的现有登录会话将失效。

## 日志与维护

保留 v3.0.0-api.113 增加的日志归档、分类保存期限及手动清理功能。管理员可以先查看符合条件的日志数量，再确认清理。运行中的消息和正在写入的日志文件继续按现有设置处理。

## 数据库与部署

数据库迁移版本升级至 **291**，增加 Passkey 凭证、账户句柄和一次性认证请求的数据表。现有账户、设备、地址簿、审计和日志保留策略继续使用。

Passkey 需要通过 HTTPS 网站访问；本机开发可以使用 localhost。反向代理应保留网页使用的 Host。升级前请备份数据库、配置和加密密钥。
