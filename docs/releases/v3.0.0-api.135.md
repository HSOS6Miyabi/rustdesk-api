# v3.0.0-api.135

## WebClient2 连接设置

从管理后台的“我的设备”“共享设备”和设备信息页连接设备时，WebClient2 会自动填写设备 ID，并默认折叠服务器设置。点击“服务器设置”可以展开 ID 服务器及公钥输入框。直接访问 WebClient2 手动连接时，服务器设置默认展开。

WebRTC 直接连接默认启用；用户主动关闭后，当前浏览器会记住此项选择。无法建立 WebRTC 连接时继续使用原有的 WebSocket 连接方式。

## 设备列表

“共享设备”列表增加“连接设备”按钮，与“我的设备”采用相同的 WebClient2 入口，保留设备名称和 ID。

桌面数据表格中的操作按钮保持单行显示。操作列根据按钮内容分配宽度；需要显示额外详情按钮时，操作列会相应加宽。手机上的卡片操作保持原有的自适应布局。

“根据内容调整列宽”会测量表格实际可用宽度，在保证日期和时间列紧凑的情况下重新分配各列宽度，避免调整后产生额外的横向滚动。如果当前显示全部列导致可用空间不足，将恢复适合窗口宽度的列显示方式。

## 测试

使用 Node.js 和 Chromium 测试验证共享设备连接入口、WebRTC 默认状态、服务器设置折叠与展开、操作按钮单行显示、表格自动调整列宽以及多种桌面和移动端窗口宽度。浏览器测试保存实际页面截图供检查。
