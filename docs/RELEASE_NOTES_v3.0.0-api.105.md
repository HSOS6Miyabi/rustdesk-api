# RustDesk API v3.0.0-api.105

本版本新增个人事件通知、设备在线状态显示和 IP 地理位置说明，并优化通知发送队列的调度及数据库查询。

## 功能更新

- 个人账户可以分别配置 MessagePusher、SMTP 邮件和 Server酱 Turbo，并为每个渠道选择订阅事件。
- 通知涵盖设备上线、离线、登记、远程连接、文件传输、安全告警、设备部署状态、远程会话操作及账户登录失败。
- 消息优先显示事件、设备名称和 ID、关联账户、来源 IP 及地理位置，正文补充设备和连接信息。
- 管理员控制台、普通用户控制台和 WebClient v2 在设备信息前显示在线状态圆点。
- 控制台的 IP 地址可附加国家、省级行政区和城市名称。地理位置查询使用服务器本地的 MaxMind 城市数据库。

## 性能与安全

- 事件进入内存缓冲区后由工作协程异步处理，发送失败后按照计划时间重试。
- 离线检查与消息重试使用到期定时器；普通管理页面仅在打开或刷新时批量请求设备状态。
- 设备重复心跳在短时间内合并处理。设备 IP 发生变化时立即记录更新。
- 为待发送消息和正在发送消息的到期查询建立组合索引。
- 各用户只能管理自己的通知渠道；服务端按账户权限检查设备状态请求。
- 推送密钥与 SMTP 密码使用 AES-GCM 加密保存。

## 升级说明

升级前请备份数据库。启动新版程序时会自动创建通知相关的数据表并更新查询索引。

使用个人消息通知前，请在服务器中设置固定的 `RUSTDESK_API_PUSH_ENCRYPTION_KEY`，至少 16 个字符。需要显示公网 IP 地理位置时，下载 MaxMind GeoLite2 City 数据库，并将 `RUSTDESK_API_GEOIP_DB` 指向对应的 `.mmdb` 文件。Docker 部署时应挂载数据库文件，并保留加密密钥环境变量。

详细设置、支持的事件和 API 示例见 [消息推送与 IP 地理位置](PUSH_NOTIFICATIONS.md)。
